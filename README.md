# Sistemas_Distribuidos

Repositorio de la asignatura Sistemas Distribuidos del grado de Ingeniería Informática por la Facultad de Ciencias Sociales y Tecnologías de la Información de la Universidad de Castilla-La Mancha.

En este Repositorio se encontrarán tanto ejemplos de las distintas sesiones impartidas en la asignatura como ejercicios de repaso.
